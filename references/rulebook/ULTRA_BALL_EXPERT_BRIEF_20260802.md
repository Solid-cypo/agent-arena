# 高级球（Ultra Ball）现行策略 — 专家讨论稿

**日期**：2026-08-02  
**卡组**：海星 + 雪妖女，3× 高级球（1121）  
**定位**：高级球是「弃 2 搜 1 宝可梦」的有损检索；**免费检索（Poffin / 手环）优先**，Ball 只在免费检索办不到或紧急补件时用。

本文供线上复盘 / 专家对齐用。实现细节见同目录 `ULTRA_BALL_POLICY_20260801.md`。

---

## 1. 一句话原则

> **先做海星线，再挖 DP；有免费检索就别打球；绝不拿关键件当弃牌。**

三闸：

| 闸门 | 问什么 |
|---|---|
| **何时打** | 现在该不该消耗一张 Ball？ |
| **搜什么** | 牌库里该拿哪一张？ |
| **弃什么** | 哪两张可以安全丢掉？ |

## 2. 分阶段策略（现行）

### 阶段 A — Mega 大海星尚未上场（开局 / 未完成 Goal）

**目的**：把「海星星 → Mega 大海星」做出来，不提前挖雪女线 / 愿增猿。

| 项目 | 现行规则 |
|---|---|
| **允许搜** | 仅 `{Mega 大海星 ex, 海星星}` |
| **禁止搜** | 愿增猿、雪童子、雪妖女、Mega 大雪妖女、土龙节节、含羞苞、喵头目、旋转罗盘等 |
| **手持 Mega + 场上已有海星星** | **禁止**再打 Ball → 优先进化 |
| **手持 Mega、场上还缺海星星** | 仅当无 Poffin/手环时，允许 Ball 挖海星星 |
| **手有 Poffin 或手环** | **禁止** Ball（先打免费检索；打完再考虑 Ball 挖 Mega） |
| **牌库里估不到海星星/Mega** | 不打 Ball（避免奖品坑乱挖） |

**例外（刻意收窄）**  
- 含羞苞 / Budew 锁手线：本轮**不**放进 Ball 白名单（宁可走别的路径）。  
- HARVEST（海星已死、转雪女打手）：允许挖 Mega 大雪妖女 / 雪童子（保险窗）。

### 阶段 B — Mega 大海星已上场，DP 未齐

**目的**：补齐 DP 套（雪童子线 → 104、愿增猿 + 恶能），861 只做保险。

| 项目 | 现行规则 |
|---|---|
| **何时 Ball** | 仅 `dp_urgent`（DP 核心未齐） |
| **优先免费检索** | 仍有 Poffin/手环且只需基础件 → **不打** Ball |
| **允许 Ball 挖** | 雪童子 / 雪妖女(104) / 愿增猿（及窗口内的 861） |
| **禁止** | 手牌已有同名目标仍再挖；DP 已齐还打 Ball |

### 阶段 C — DP 已齐 / 中后盘

Ball 不再高优先；861 只在「海星濒死/离场」或「富余保险窗」内检索（S 策略，与 Ball 共用检索分）。

## 3. 弃牌规则（打球时丢哪两张）

### 禁止弃（黑名单）

| 优先级 | 卡 |
|---|---|
| 绝对不弃 | 海星星、Mega 大海星、基本水能量、棱镜 |
| 硬保护 | 希尔达、手环、Poffin、夜之伸展器、愿增猿、雪童子（场上无线时）、莉莉艾/克里宾/萨瓦托、另一张高级球 |

若手牌里**凑不出 2 张安全弃牌** → **整张 Ball 不打**。

### 优先弃（废牌池）

危险废墟 → 瓦利的慈悲 → 多余 Boss → 不公平的印章 → 裁判（视窗口）→ 死风车 → 引火/多余恶能/交替（视撤退需求）

---

## 4. 和免费检索的分工

```text
需要「基础宝可梦」上场
  → Poffin / 手环（免费）
  → 没有免费检索，且缺海星星 → 高级球（仅海星星）

需要「Mega 大海星 / 进化位」
  → 希尔达（若支援者槽可用）
  → 否则高级球（仅 Mega；且此时手中应已无 Poffin/手环）

需要「104 / 愿增猿」且 Mega 已在场
  → 先手环/Poffin（若目标是基础）
  → 需要 104 或免费检索已空 → 高级球
```

**设计取舍（请专家拍板）**  
现行 UB-3 **严格**：Mega 前只要手里还有 Poffin/手环，**一律不打 Ball**——即使目标是 Mega。  
理由：Ball 在「Mega 其实在奖品」时会误挖愿增猿/雪童子，审阅包里损失很大。  
代价：有时明明 Ball 能直接拿 Mega，却被要求先打完 Poffin。
