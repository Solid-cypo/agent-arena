## 莉莉艾 / 裁判：洗抽后手牌怎么写

发动 **莉莉艾、裁判** 等「洗切牌库再抽牌」后，手牌会与起手/奖品区 **脱钩**，Ultra Ball 弃牌可能来自洗抽后的手牌（例如 seed798 的「瓦利的慈悲」）。

**请在 `本回合操作` 里、`[操作] 使用莉莉艾`（或裁判）的下一行追加：**

```
  N. [备注] 莉莉艾抽牌后手牌: 基本水能量, Mega 大雪妖女 ex, …
```

- **新导出的 TestRun log 已自动带此行**（`export_review_manual`）；专家改路线时若仍用莉莉艾/裁判，请保留或更新该备注。
- 若 Goal 已达成、后面无决策步：`回合结束手牌` 可写 `（Goal 已达成，手牌见上行备注）`。
- **不要**只写 `莉莉艾抽8` 而又缺少「抽牌后手牌」备注（Ball 弃牌无法审计时）。

裁判同理：`[备注] 裁判抽牌后手牌: …`

## 动作行格式（与导出一致）

```
  1. [抽牌] 抽到 宝可梦手环
  2. [操作] 使用高级球检索 喵头目 ex，丢弃 …
  3. [贴能] 基本水能量 → 海星星（替补席）
  4. [进化] 海星星 → Mega 大海星 ex
  5. [撤退] 撤退后战斗场 ← Mega 大海星 ex
```

常用类型：`[布置]` `[抽牌]` `[放置]` `[操作]` `[贴能]` `[进化]` `[特性]` `[丢弃]` `[撤退]` `[备注]`

- 支援者、道具统一用 **`[操作]`**，不要自造 `[使用支援者]` 等标签。
- 卡牌名用 log 里已有的 **中文名**（如「喵头目 ex」「基本水能量」）。
- 纠错后 **删掉** 矛盾的 `[备注]`（如「无水跳过贴能」与后续 `[贴能]` 并存）。
- 序号可乱，我们会重排；**不要** 写 `// [CORRECT: …]` 注释。

## 规则速查（改路线时别踩）

1. **先攻 T1 不能打支援者**（`role=先攻` 且 My-T1）。
2. **每回合最多 1 张支援者**。
3. **高级球** 只能检索 **宝可梦**，不能检索能量。
4. **宝可梦手环** 不能检索 ex / V（Rule Box）。
5. **Ultra Ball / 手环** 弃牌必须来自当时手牌。
6. 进化 **Mega 大海星** 后若战斗场仍是占位怪，常需 **贴能 + 撤退** 换上来。
