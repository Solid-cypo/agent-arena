## 按样本类型怎么做

| 页眉样本类型 | 数量 | 你要做什么 |
|-------------|------|-----------|
| **负面** negative | 60 | 能 Goal → 改 `本回合操作`（+ Setup 若需）→ `edited`；结构死局 → `unreachable` |

Goal 定义：**Mega 大海星 ex + 基本水/棱镜水 在战斗场**，且在回合上限内（先攻 ≤3T，后攻 ≤2T，见页眉 `turn_limit`）。

## 动作行格式（与导出一致）

```
  1. [抽牌] 抽到 宝可梦手环
  2. [操作] 使用高级球检索 喵头目 ex，丢弃 …
  3. [贴能] 基本水能量 → 海星星（替补席）
  4. [进化] 海星星 → Mega 大海星 ex
  5. [撤退] 撤退后战斗场 ← Mega 大海星 ex
```

常用类型：`[布置]` `[抽牌]` `[放置]` `[操作]` `[贴能]` `[进化]` `[特性]` `[丢弃]` `[撤退]` `[备注]`

- 支援者、道具统一用 **`[操作]`**，不要自造 `[使用支援者]` 等标签。
- 卡牌名用 log 里已有的 **中文名**（如「喵头目 ex」「基本水能量」）。
- 纠错后 **删掉** 矛盾的 `[备注]`（如「无水跳过贴能」与后续 `[贴能]` 并存）。
- 序号可乱，我们会重排；**不要** 写 `// [CORRECT: …]` 注释。

## 规则速查（改路线时别踩）

1. **先攻 T1 不能打支援者**（`role=先攻` 且 My-T1）。
2. **每回合最多 1 张支援者**。
3. **高级球** 只能检索 **宝可梦**，不能检索能量。
4. **宝可梦手环** 不能检索 ex / V（Rule Box）。
5. **Ultra Ball / 手环** 弃牌必须来自当时手牌。
6. 进化 **Mega 大海星** 后若战斗场仍是占位怪，常需 **贴能 + 撤退** 换上来。
